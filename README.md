Customer Segmentation Analysis

Project Overview

This project explores customer demographics, annual income, and spending scores using SQL and Power BI. The goal is to identify customer segments and uncover patterns that can help businesses make more informed marketing and customer engagement decisions.

Tools Used

* Microsoft SQL Server Management Studio (SSMS): Data exploration, querying, aggregation, and analysis using SQL.
* Power BI Desktop: Data visualization and interactive dashboard development.
* CSV: Dataset storage and import.

Dataset Description

The dataset contains 2,000 customer records, including:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score
* Profession
* Work Experience
* Family Size

Key Analysis Areas

* Total customer count and average customer age.
* Customer distribution by gender.
* Average spending score by profession.
* Average annual income by profession.
* Spending score across age groups.
* Spending score across income groups.
* Data quality checks for missing values and duplicate customer IDs.

Key Findings

* The dataset contains 2,000 customer records.
* The average customer age is approximately 48.96 years.
* Female customers account for 59.3% of the dataset, while male customers account for 40.7%.
* Entertainment and Artist customers have the highest average spending scores among the professions analyzed.
* Executives have the highest average annual income among the professions analyzed.
* Customers under 20 have the highest average spending score among the age groups analyzed.
* Thirty-five records have missing profession values.

Business Recommendations

* Develop customer engagement strategies tailored to different demographic groups.
* Explore the needs and preferences of customers across professions and age groups.
* Avoid assuming that higher income automatically means a higher spending score.
* Investigate missing customer information to improve data quality.
* Use customer segmentation insights to guide further marketing research and campaign testing.

Dashboard

The Power BI dashboard presents customer demographics, average income, spending patterns, and interactive filters for exploring customer segments.

Limitations

The dataset contains spending scores rather than actual transaction amounts. Therefore, this analysis does not measure actual revenue, purchase frequency, or customer lifetime value. The findings describe patterns in this dataset and should not be treated as proof of causation.

Conclusion

This project demonstrates practical skills in SQL-based data analysis, data quality assessment, customer segmentation, and Power BI dashboard development.
